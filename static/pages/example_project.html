System Information Map

Southern Iowa Electric Cooperative, inc.

This project includes several moving parts. There are several systems within this project, from Map Generation, to rendering, to information collection. This project is currently in active development, a version has been released for production, but the system continues to be improved. The process currently starts with a Open Source project, TileServer GL, this is being removed for a more streamlined process. The Tileserver Generates a .mbtiles file, this file is automatically distributed to one of our servers to be rendered for our users. The actual System Map takes the .mbtiles and renders this as a base map, we also have a platmap, and several open source maps used as base layers. We then collect information from several databases, most notably our GIS database, to render various interactable overlays and items on the map. These items include poles, line segments, meters, etc...
